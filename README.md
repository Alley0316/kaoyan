# 四校考研真题高频考点与难度分析

安徽大学 · 黑龙江大学 · 云南民族大学 · 西安工业大学 四校考研真题的**高频考点整理**与**相对本校参考书范围的难度分析**，用于择校判断。

## 目录

| 目录 | 内容 |
|---|---|
| `v1/` | 旧版：高频考点四册（docx＋pdf）＋《四校真题相对参考书目难度评估》 |
| `v2/` | 融合版：高频考点复核版四册＋《四校真题考点与难度复核总结》（10 页） |
| `v3/` | 当前版：难度复核总结（12 页，补黑龙江 2021 当年书目、云南 2025／2026 官方书目、西安 2025 书目三处核证） |
| `.工作数据/` | 复核考点数据（`复核考点.json`）与考点文档生成器 |
| `.高频考点工作/` | 四校真题提取数据、`官方大纲/` 证据原件、生成与核验脚本 |
| `.难度评估依据/` | 早期难度评估脚本与报告数据 |

四册高频考点合计 249 条复现主题、62 条单次关注、1227 条引用记录（42 页）。v3 总结为当前结论版本，四册沿用 v2 原件。

## 使用方式

1. 直接看 `v3/四校真题考点与难度复核总结.pdf`：先结论（参考等级与判断），再逐校依据、范围来源、限制与未核事项。
2. 逐校复习时配合 `v2/` 四册《高频考点复核版》使用：米色为章节、红色为题型、黄色为真题摘录，每条给出训练要求与已确认年份。
3. 页码均指各校《历年真题打印复核版》PDF 的页脚印刷页码，可直接回查原卷。

## 结论口径（重要）

- 难度按**相对本校对应年份参考书范围**评定，不掺入院校名气、学科排名、报考竞争与录取率。
- 等级数字（1–5 级）只用于跨校横向对照，不与具体题目难度一一对应；范围贴合、作答加工、答案开放度三个维度分开记录。
- 年次统计以同校同学科不同年份为单位，同年多题不重复计次；主题包含考点、专题与题型，不是互斥原子考点，引用数不等于独立题数。
- 回忆版与缺卷会造成遗漏：年次是已确认证据的下限，不换算命中率。
- 完整教材未逐页对照，因此结论是「相对参考书范围与命题要求」的分析性判断，不是覆盖率证明。

## 复现说明

- Python 依赖：`python-docx`（生成器）、`pdfplumber`（提取）。
- 生成器顶部 `O` 变量为输出目录，路径按本机工作区硬编码为绝对路径，换机器需同步修改：`.工作数据/生成考点文档_v2.py`（四册）、`.高频考点工作/生成难度总结文档.py`（总结）。
- PDF 渲染：`python3 .高频考点工作/render_local.py <docx> --output_dir <目录> --emit_pdf`，脚本内固定使用系统 `/usr/bin/soffice` 与 `/usr/bin/pdftoppm`。
- 生成器不会改动上游数据：请勿重跑 `修订考点.py` / `统计考点.py` / `精修考点.py` 覆盖 `.工作数据/复核考点.json`。
