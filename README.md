## 使用方式

1. 先看 `v5/四校真题考点与难度对比_v5.pdf`：先结论（参考等级与判断），再 v5 分段与书目变更对照表、参考书单总表、逐校依据、范围来源、限制与未核事项。
2. 再打开本校那一册（`v5/<学校>_高频考点_v5.pdf`）：册内先列该册有哪几段（科目＋科目代码＋年份＋页码）与各段参考书，正文按「段落 → 参考书」分块编号；米色为分块／章节、红字为题型、黄色为真题摘录。
3. 某一年的题要回到该年所属那一段的书目去看：四校的科目代码与指定教材都随年份变过，不要用最新书目评旧卷。
4. 页码均指各校《历年真题打印复核版》PDF 的页脚印刷页码，可直接回查原卷。
5. `v4/`、`v3/` 保留为历史版，用于对照分册口径与编号方式的变化。

## 结论口径（重要）

- 难度按**相对本校对应年份参考书范围**评定，不掺入院校名气、学科排名、报考竞争与录取率。
- 等级数字（1–5 级）只用于跨校横向对照，不与具体题目难度一一对应；范围贴合、作答加工、答案开放度三个维度分开记录。
- 年次统计以同校同学科不同年份为单位，同年多题不重复计次；主题包含考点、专题与题型，不是互斥原子考点，引用数不等于独立题数。
- 回忆版与缺卷会造成遗漏：年次是已确认证据的下限，不换算命中率。
- 完整教材未逐页对照，因此结论是「相对参考书范围与命题要求」的分析性判断，不是覆盖率证明。

## 复现说明

### v5（当前版）

- 一条命令跑完整条流水线（在仓库根目录执行，用带 `python-docx` 的解释器）：

  ```bash
  bash .工作数据/跑v5.sh
  ```

  顺序为：`准备v5数据.py`（分段）→ `补正v5证据.py`（占位证据的卷别年份）→
  `核对v5真实性.py`（硬校验）→ `生成v5考点文档.py`（四册 docx）→ `render_pdf.py`（转 PDF）→
  记录 `v5页数.json` → `生成v5总结文档.py` → `render_pdf.py`（总结 PDF）→
  `核验v5.py` ＋ `核验v5总结.py`（机械核验）。

- 各步骤单独用途：
  1. `python3 .工作数据/准备v5数据.py` → `.工作数据/v5考点数据.json`、`v5分段清单.json`（自检：唯一考点集、分册条目、证据覆盖三项与 v4 一致）；
  2. `python3 .工作数据/补正v5证据.py` → 原地补正占位证据，并写 `.工作数据/v5证据补正清单.json`（12 条移出／3 条改卷别／4 条存疑移出）；
  3. `python3 .工作数据/核对v5真实性.py` → 逐条回原卷核对题号、卷名、年份、页码与原文，写 `v5真实性核对.json`，退出码 1 表示有硬错误；
  4. `python3 .工作数据/生成v5考点文档.py` → `v5/*.docx`；
  5. `python3 .工作数据/render_pdf.py v5` → 转 PDF（可选 `--png <目录>` 逐页渲染 PNG）；
  6. `python3 .工作数据/生成v5总结文档.py` → `v5/四校真题考点与难度对比_v5.docx`（需先有 `v5页数.json`）；
  7. `python3 .工作数据/核验v5.py`、`python3 .工作数据/核验v5总结.py` → 编号连续性、条目完整性、逐卷页码、统计数字、关键书目事实与版面边界。

- 注意：`准备v5数据.py` 的自检问题只打印不改变退出码（否则 `set -e` 会中断流水线、导致 JSON 不落盘）；把关由第 3、7 步负责。
- `v5/*.docx` 为中间产物，出完 PDF 后可删，按上面顺序可随时重建；难度总结文字沿用 `.工作数据/v4总结模板.py`（由 v3 原文精确抽取），v5 只替换统计表、新增分段对照表与书目总表、并按官方目录改写安徽一节的「范围来源」。

### v4（上一版，保留对照）

- 流水线（在仓库根目录执行，全部用带 `python-docx` 的解释器，例如
  `/home/zyf/.dsh/shared-runtime/dependencies/python/bin/python3`）：
  1. `python3 .工作数据/准备v4数据.py` → 生成 `.工作数据/v4考点数据.json`（按科目／参考书归组，并做归属校验）；
  2. `python3 .工作数据/生成v4考点文档.py` → `v4/*.docx` ＋ `.工作数据/v4册清单.json`；
  3. `python3 .工作数据/生成v4总结文档.py` → `v4/四校真题考点与难度对比_v4.docx`（需先有 `v4页数.json`）；
  4. `python3 .工作数据/render_pdf.py v4 --png <目录>` → 转 PDF 并逐页渲染 PNG；
  5. `python3 .工作数据/核验v4.py` → 编号连续性、条目完整性、书单前置、版面边界机械核验。

- 难度总结文字由 `.工作数据/提取v3总结内容.py` 从 `生成难度总结文档.py` 精确抽取为 `v4总结模板.py`，
  v4 只替换统计表与新增参考书单总表，避免手抄数字出错；重跑时按 1→2→3 顺序执行即可。

### v3（历史版）与通用

- Python 依赖：`python-docx`（生成器）、`pdfplumber`（提取）。**本机默认 `python3` 未安装 `python-docx`**，需用带该依赖的解释器，否则报 `ModuleNotFoundError: No module named 'docx'`。
- v3 重建：先把 `O` 指向目标目录，再跑 `.工作数据/生成考点文档_v2.py`（四册）与 `.高频考点工作/生成难度总结文档.py`（总结）。
- 复现验收：重跑 v3 后不要比对 docx 整体字节（打包时间戳不同），应逐部件比对内部 19 个部件的 SHA-256；部件全同即内容一致。
- 生成器不会改动上游数据：请勿重跑 `修订考点.py` / `统计考点.py` / `精修考点.py` 覆盖 `.工作数据/复核考点.json`。
